A few details about how these features work +

Assigned work can search saved records, save notes, prepare an unsent reply, or create a weekly PDF. You can inspect each step and review the result. Email sending in the current build requires your review and a configured sending connection.

Document imports are reviewed before saving. Grocery checkout takes place with the store. Publishing a guest booking page requires separate setup. Capture notes and navigate with Commands, or use ⌘/Ctrl + Shift + P.

05 / Bring your world together

All the places
life comes in.

Connect the sources you use. Zelos keeps its own archive on your computer, so the next question starts with context.

Mail & messages

Gmail · iCloud · Outlook · Yahoo · Fastmail · IMAP
Messages on Mac (preview) · WhatsApp exports

Time & meetings

Calendar links · CalDAV · .ics files · Fireflies

Projects & knowledge

Slack · GitHub · Linear · Todoist · RSS & Atom · Local folders

What you need to connect +

Email providers may require an app password. Google and Microsoft OAuth require your own client registration; Outlook.com needs that additional setup. Other services use credentials you supply. Read the setup guide →

Messages import reads text already synced to your Mac, requires macOS Full Disk Access, and is available in the current development build. WhatsApp import uses an exported chat file. Zelos checks connected sources while it is open.

Before your first launch +

These are community builds. The Mac app is not notarized by Apple, and Windows does not recognize a verified publisher. Your computer may display a warning when you open it. Read the installation guide before deciding to continue.

Zelos is a desktop app and checks sources while open. Online AI providers may charge for usage. A local model can process your requests on your computer. You can inspect the source code and release checksums.
